《简单连点器 Pro》隐私政策

一、我们收集哪些信息

本应用不收集、不存储、不上传任何个人信息。

  • 不申请网络权限，应用完全离线运行，不具备联网能力；
  • 不读取屏幕内容（无障碍服务声明 canRetrieveWindowContent=false）；
  • 不采集设备标识符、位置、通讯录、相册、短信、通话记录等任何系统数据；
  • 不集成任何第三方统计、广告、崩溃上报 SDK。

二、本地保存的数据

为记住你的设置，应用仅在本机保存以下内容（SharedPreferences）：

  • 多套点击方案：方案名称、点击间隔、按下时长、长按时长、滑动时长、双击间隔、 随机幅度、坐标抖动、总次数、运行时长、启动倒计时、循环方式、手势类型；
  • 各方案中由你手动添加的点击点位坐标；
  • 深色模式偏好；
  • 是否已同意本隐私政策与用户协议。

上述数据仅存于你的设备本地，卸载应用即被删除，任何情况下都不会离开你的设备。

你可以通过主界面「导出 / 导入」功能，借助系统文件选择器把方案保存为 JSON 文件， 或从你选择的文件恢复方案。该过程完全由你主动发起，应用不会自动读写任何文件， 也不会把文件内容上传或分享给任何人。

三、悬浮窗权限的用途

悬浮窗权限（SYSTEM_ALERT_WINDOW）仅用于在屏幕上层显示一个控制面板与若干手势点位标记， 使你可以在其他应用之上随时开始 / 停止手势、拖动调整位置。 该权限不用于读取、录制、截取或上传屏幕内容。

四、无障碍服务的用途

无障碍服务（AccessibilityService）仅用于调用系统提供的 dispatchGesture 接口， 在你设定的屏幕坐标派发模拟手势（单击、双击、长按、滑动）。该服务：

  • 不读取窗口内容，不获取界面文字、密码或输入内容；
  • 不记录、不保存任何按键内容；仅在自动点击运行期间识别「音量下键」动作用于紧急停止， 停止后立即恢复正常，不影响音量键本身的功能；
  • 不联网，不把任何数据传出设备。

你可以在系统「设置 → 无障碍」中随时关闭该服务，关闭后自动手势立即失效。
